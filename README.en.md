# Leonardo Castignani's Personal Portfolio

This is the repository for my personal portfolio website, built with [Astro](https://astro.build/) and [Tailwind CSS](https://tailwindcss.com/) to ensure top performance and a modern design.

🔗 **Live Demo:** [Website](https://www.leonardocastignani.it/)

---

## ✨ Key Features

-   **Modern and Responsive Design**: Perfect display on desktop, tablet, and mobile.
-   **High Performance**: Built with Astro for near-instant loading times.
-   **Multi-language Support (i18n)**: Content available in Italian and English.
-   **On-Scroll Animations**: Sections smoothly fade in as you scroll down the page.
-   **Functional Contact Form**: Integration with form management via [Netlify](https://www.netlify.com/) to receive emails.
-   **SEO Friendly**: Optimized structure for search engines.

## 🛠️ Technologies Used

-   **Framework**: [Astro](https://astro.build/)
-   **Styling**: [Tailwind CSS](https://tailwindcss.com/)
-   **Hosting**: [Netlify](https://www.netlify.com/)

## 🚀 Main Commands

All commands should be run from the project's root folder.

| Command           | Action                                               |
| :---------------- | :--------------------------------------------------- |
| `npm install`     | Installs the necessary dependencies.                 |
| `npm run dev`     | Starts the local development server on `localhost:4321`. |
| `npm run build`   | Creates the production build in the `./dist/` folder. |
| `npm run preview` | Starts a server to preview the production build.     |
